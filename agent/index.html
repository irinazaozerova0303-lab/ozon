Справка

    
Как это работает

    
    
      
  1. Загрузите Excel-выгрузки Ozon (продажи, остатки, реклама и, по возможности, себестоимость, финансы, поставки, товары, отзывы).
    2. 
      
  2. Агент сам определяет тип файла и колонки по заголовкам. Проверьте определение и поправьте вручную, если нужно.
    3. 
      
  3. Данные объединяются по SKU. Показатели считаются только из того, что реально есть в файлах — никакие цифры не придумываются.
    4. 
      
  4. Если данных для расчёта не хватает, так и написано: «Недостаточно данных».
    5. 
      
  5. Действия с финансовым риском (цена, скидка, рекламный бюджет/ставка, поставка) никогда не выполняются автоматически — агент не подключён к личному кабинету Ozon и не может ничего там менять. Он только готовит рекомендацию и ждёт вашего подтверждения в разделе «Решения».
    6.

Допущения по умолчанию

    
Настраиваются кнопкой ⚙ в шапке. Везде, где допущение применено, это явно помечено в отчёте.

    
    
      
  • Срок поставки не указан → риск дефицита считается при запасе менее 7 дней.
    • 
      
  • Порог избыточного запаса — более 60 дней продаж.
    • 
      
  • Падение выручки к прошлому периоду ≥ 20% — проблема; ≥ 40% — аутсайдер.
    • 
      
  • Рост выручки к прошлому периоду ≥ 15% — растущий товар.
    • 
      
  • Ухудшение ДРР ≥ 5 п.п. к прошлому периоду — сигнал по рекламе.
