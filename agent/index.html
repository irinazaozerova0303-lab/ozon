Загрузка данных

Минимум для отчёта: продажи, остатки, реклама. Для полной экономики добавьте себестоимость, финансы, поставки, товары и отзывы. Ничего не отправляется никуда — все файлы обрабатываются локально в вашем браузере.

Подключение к Ozon Seller API опционально — вместо ручной загрузки остатков и продаж

У Ozon Seller API нет CORS — браузер не может обратиться к нему напрямую, поэтому нужен маленький прокси-сервер (бесплатный Cloudflare Worker, разворачивается за 2 минуты, ключ передаётся только через него и не покидает ваш браузер и ваш прокси). Подробности и код прокси — во вкладке «Справка». Финансы (приблизительно) и отзывы теперь тоже можно подтянуть. Реклама (свой ключ) и себестоимость (Ozon её не хранит) — пока только файлом.

Реклама (Ozon Performance API) — отдельный ключ

Другой раздел кабинета Ozon: Настройки → API-ключи → Performance API → создайте сервисный аккаунт → «Добавить ключ». Client ID копируйте без хвоста «@advertising.performance.ozon.ru» — только цифры. Если обновляли код прокси-сервера раньше (для Seller API) — обновите его ещё раз кодом из «Справки», старая версия рекламу не пропустит. Список кампаний — быстро. Расход/показы/клики по SKU — через отдельный отчёт Ozon, только по кампаниям со статусом «идёт» (по 10 штук за раз, Ozon строит отчёт асинхронно — при большом числе активных кампаний загрузка может занять несколько минут, но кнопку нажимать повторно не нужно, агент сам проходит все партии). После загрузки нажмите «Обновить всё» или «Обработать данные», чтобы это попало в отчёт.

Как это работает

    
    
      
  1. Загрузите Excel-выгрузки Ozon (продажи, остатки, реклама и, по возможности, себестоимость, финансы, поставки, товары, отзывы).
    2. 
      
  2. Агент сам определяет тип файла и колонки по заголовкам. Проверьте определение и поправьте вручную, если нужно.
    3. 
      
  3. Данные объединяются по SKU. Показатели считаются только из того, что реально есть в файлах — никакие цифры не придумываются.
    4. 
      
  4. Если данных для расчёта не хватает, так и написано: «Недостаточно данных».
    5. 
      
  5. Действия с финансовым риском (цена, скидка, рекламный бюджет/ставка, поставка) никогда не выполняются автоматически — агент подключается к Ozon только на чтение (остатки, продажи) и не может ничего менять в личном кабинете. Он только готовит рекомендацию и ждёт вашего подтверждения в разделе «Решения».
    6. 
    


    
Подключение к Ozon Seller API

    
Ozon Seller API не поддерживает запросы напрямую из браузера (нет CORS) — это ограничение самого Ozon, а не этого инструмента. Поэтому нужен маленький бесплатный прокси-сервер, который просто пересылает запрос дальше и добавляет разрешающий заголовок. Ваш Client-Id и Api-Key при этом остаются только в вашем браузере и передаются напрямую в ваш собственный прокси и в Ozon — больше никуда.

    
    
      
  1. Зайдите на dash.cloudflare.com, зарегистрируйтесь (бесплатно) и откройте раздел «Workers & Pages» → «Create Worker».
    2. 
      
  2. Удалите код-заготовку и вставьте код из файла agent/proxy/cloudflare-worker.js этого репозитория (текст также ниже — можно скопировать прямо отсюда).
    3. 
      
  3. Нажмите «Deploy». Скопируйте адрес вида https://ваш-воркер.workers.dev.
    4. 
      
  4. Вставьте этот адрес, Client-Id и Api-Key (Настройки → API интеграции → Seller API в личном кабинете Ozon, тип токена — Admin) в блок «Подключение к Ozon Seller API» на вкладке «Загрузка данных» и нажмите «Проверить подключение».
    5. 
    

    
    

    
Через API автоматически подтягиваются остатки, названия товаров, продажи (аналитика Ozon), финансовые операции, отзывы и список рекламных кампаний. Себестоимость Ozon не хранит и API не отдаёт — вводите её файлом или вручную. Разбивка финансов по статьям (комиссия/логистика/хранение) — приблизительная категоризация по названию операции в выписке Ozon, а не бухгалтерская проводка; сверяйте с отчётом Ozon при существенных расхождениях. Отзывы через API доступны не на всех тарифах Ozon.

    
Реклама (Performance API) — отдельный ключ

    
У рекламы в Ozon свой, отдельный от Seller API ключ и свой способ входа (логин/пароль здесь ни при чём — нужны именно Client-Id и Client-Secret этого раздела).

    
    
      
  1. В личном кабинете Ozon: Настройки → API-ключи → вкладка «Performance API».
    2. 
      
  2. Если сервисного аккаунта ещё нет — создайте («Создать аккаунт»), затем «Добавить ключ».
    3. 
      
  3. Скопируйте Client ID без хвоста «@advertising.performance.ozon.ru» — только цифры, и Client Secret.
    4. 
      
  4. Вставьте их в блок «Реклама (Ozon Performance API)» на вкладке «Загрузка данных» → «Сохранить ключи» → «Проверить подключение».
    5. 
      
  5. Если код прокси-сервера обновляли раньше (до появления рекламы в агенте) — обновите его ещё раз тем же способом (Edit code → вставить код из кнопки выше → Deploy): адрес воркера при этом не меняется, обновлять его в настройках не нужно.
    6. 
    

    
Пока через рекламный API подтягивается только список кампаний (название, статус, бюджет). Расходы, показы, клики и ДРР по кампаниям Ozon отдаёт через отдельный асинхронный отчёт — это следующий шаг в разработке, сейчас для этих цифр по-прежнему нужен файл.

    
Важный нюанс идентификаторов: в остатках Ozon использует ваш собственный артикул (offer_id), а в аналитике продаж — свой внутренний числовой SKU. Агент сам сопоставляет их через список товаров перед объединением; если сопоставить не удалось, он покажет внутренний ID Ozon и явно предупредит об этом в журнале загрузки, а не подставит данные наугад.
